# Lineamientos TL – Componentes Dinámicos Accesibles

## Manejo del foco
- Al abrir componente dinámico mover foco al nuevo contenido
- Al cerrar regresar foco al elemento anterior
- Evitar pérdida de foco después de render dinámico

## Uso de ARIA
- aria-live para contenido dinámico
- aria-expanded para elementos colapsables
- aria-modal para modales

## DOM dinámico
- Evitar manipulación directa del DOM
- Usar estado de React
- No recargar la página

## Accesibilidad
- Navegación por teclado obligatoria
- Mantener estructura semántica
